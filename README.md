# Little Lift

A native, local-first workout logger for iPhone and Apple Watch, with routines, fixed Watch controls, training Progress and explicit coach sharing.

**[Project overview, screenshots and setup →](LittleLift-monochrome/README.md)**

Open [LittleLift.xcodeproj](LittleLift-monochrome/LittleLift.xcodeproj) in Xcode, or double-click **Run Little Lift.command** inside `LittleLift-monochrome` to use existing paired simulators.

```sh
cd LittleLift-monochrome
bash scripts/verify-mac.sh
```
